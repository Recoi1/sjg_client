🌟 Key Features
Native PC Performance: Runs directly on x86-64 hardware without the overhead of traditional emulation.

High Refresh Rate & Resolution Support: Play at arbitrary resolutions (4K+) and unlocked or ultra-smooth high framerates.

Modern Control Options: Full support for modern gamepads (DualSense, Xbox, Switch Pro Controller) as well as Mouse & Keyboard input for star pointer controls.

Enhanced Visuals: Support for high-resolution texture packs, wide-aspect ratios (16:9, 21:9, 32:9), and custom shader options.

Low Latency Input: Minimal input lag compared to standard Wii emulation.

Quick Loading: Lightning-fast loading times thanks to native file system access.
