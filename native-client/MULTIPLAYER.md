The portable ROM builder is implemented. One executable opens a drop window when local data is absent, verifies RMGE01 USA revision 0 by its original executable SHA-1, extracts all disc resources into a fresh staging directory, and commits the completed installation. It then runs the native game using those local resources and the user's original ROM. No external compiler is needed. Cancelling and failed imports discard only their own staging directory. Existing game data is never overwritten. Saves use the portable folder's userdata directory; the development save is unchanged.

Boot resources formerly compiled into the executable now load from the validated ROM. Tests can still load their private prepared boot resources. The package uses an explicit file allowlist: executable, required runtime libraries, notices and instructions. It excludes game data, ROMs, saves, HD video/texture packs and custom character assets. tools/package-portable.py checks the current verification hash and checks the executable for the former boot payloads before creating the ZIP. Importing modifies only local files; do not share a folder after adding game-data, userdata or mods.
